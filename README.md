# Dead Woods

Bodycam-Taktikshooter (Unreal Engine 5). Dieses Repository enthält nur die Downloads.

**Download:** [neueste Version](https://github.com/fynnsim785-sudo/deadwoods/releases/latest) → `DeadWoods.exe` herunterladen und doppelklicken.
Das Spiel installiert sich nach `%LOCALAPPDATA%\Programs\Dead Woods` und startet sofort.

`version.json` liest das Spiel beim Start: Ist eine neuere Version da, erscheint im Hauptmenü ein Update-Hinweis.

Windows zeigt beim ersten Start evtl. „Der Computer wurde durch Windows geschützt“ (unsignierte Datei): *Weitere Informationen* → *Trotzdem ausführen*.

Umgebung: Poly Haven (CC0). Gegner-Modell: „S.W.A.T. Operator – 4k Followers Special Remaster“ von SpatialNeglect (Fab), CC BY 4.0.
